# ☁️ CloudVault

A modern cloud storage and file management platform inspired by popular cloud storage services. CloudVault allows users to securely upload, organize, preview, search, share, and manage files through a clean and responsive web interface.

Built with **Next.js**, **TypeScript**, **Appwrite**, and **Tailwind CSS**, this project demonstrates authentication, file storage, database management, and modern full-stack web development.

> 🚧 **Project Status:** Completed as a learning project and production-inspired implementation.

---

## 📌 Features

### 🔐 Authentication
- Secure user authentication
- Email-based OTP verification
- User session management
- Protected routes

### 📁 File Management
- Upload files securely
- Rename files
- Delete files
- Download files
- Preview supported files
- View detailed file information

### 📂 Organization
- Separate categories for:
  - Documents
  - Images
  - Videos
  - Audio
  - Other Files
- Dashboard with storage overview
- Recent uploads section

### 🔍 Search & Filter
- Global file search
- Sort files by different criteria
- Filter files by category

### 🤝 File Sharing
- Share files with others
- Copy shareable links
- Manage shared files

### 📱 Responsive UI
- Desktop layout
- Tablet support
- Mobile-friendly navigation

# ⚙️ Installation

## Clone the repository

```bash
git clone https://github.com/shankarsala/CloudVault.git
```

## Navigate into the project

```bash
cd CloudVault
```

## Install dependencies

```bash
npm install
```

## Create Environment Variables

Create a `.env.local` file in the root directory.

```env
NEXT_PUBLIC_APPWRITE_ENDPOINT=

NEXT_PUBLIC_APPWRITE_PROJECT=

NEXT_PUBLIC_APPWRITE_DATABASE=

NEXT_PUBLIC_APPWRITE_USERS_COLLECTION=

NEXT_PUBLIC_APPWRITE_FILES_COLLECTION=

NEXT_PUBLIC_APPWRITE_BUCKET=
```

> Fill these values with your Appwrite project configuration.

---

## Run the development server

```bash
npm run dev
```
